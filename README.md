# Maison Be Residences — Luxury Real Estate Web Application

An ultra-luxury Next.js + React landing page for **Maison Be Residences** (Nigeria), engineered with high-end editorial aesthetics, interactive floor plan selectors, milestone investment breakdown, cross-fading hero architectural slideshow, and lead-generation modals.

---

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### 2. Build for Production
```bash
npm run build
npm run start
```

---

## 💎 Features & Architecture
- **Framework:** Next.js 14 (App Router) + React 18 + TypeScript
- **Styling:** Tailwind CSS + Custom Dark Luxury Theme (`#070c16`, `#0c1424`, `#d4af37`)
- **Typography:** Google Fonts — *Prata* (Editorial Serif Headings), *Plus Jakarta Sans* (Body), *JetBrains Mono* (Specifications & Metrics)
- **Authentic Branding:** Embedded official Maison Be gold arch monogram logo (`public/images/maison-be-logo.jpeg`)
- **Atmospheric Cross-Fade Hero:** 4 architectural renders with animated progress indicators, CAD blueprint watermark, and primary CTAs
- **Curated Residences Selector:** Interactive tabs for 1-Bed, 2-Bed, 3-Bed Suites, and Signature Sky Penthouses with specs and blueprint downloads
- **5-Star Hospitality Amenities:** 8 luxury service cards with custom icons
- **Transparent Milestone Investment:** 10/40/10/40 milestone payment schedule
- **Prime Location Map:** Dark radar coordinate map with travel times to airport and business hubs
- **Lead Capture & VIP Booking:** Interactive consultation booking and instant PDF monograph download modal
- **Floating WhatsApp Concierge:** Pulsating direct WhatsApp chat button linking to senior portfolio advisors
